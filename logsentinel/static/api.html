Local API reference

All endpoints use JSON responses. Imports use multipart form data. No authentication: bind to loopback only.

Full OpenAPI schema →

METHOD ENDPOINT PURPOSE
GET/api/labIsolated scenario catalog and replay limit
POST/api/lab/replayExactly one scenario or alert_id, plus settings; read-only engine replay
PUT/api/alerts/{id}/notebookSave assessment, observation, hypothesis, next_step with evidence snapshot
GET/api/notebooksSaved manual investigations, including removed alerts
GET/api/notebooks/{id}Manual notes and the saved evidence snapshot
GET /api/health Application and database health
POST /api/demo Import bundled synthetic events
POST /api/import file, format, year, timezone_offset
GET /api/events q, source, event_type, source_ip, user, host, start, end, limit, offset
GET /api/events/{id} Normalized event and raw record
GET /api/alerts severity, status, limit, offset
GET /api/alerts/{id} Detection explanation and evidence
PATCH /api/alerts/{id} Set status: new, investigating, resolved
GET / PUT /api/settings Read / replace thresholds and reanalyze
GET /api/stats Counts, sources, severity, hourly activity

Examples

curl -X POST http://127.0.0.1:8765/api/demo
curl 'http://127.0.0.1:8765/api/events?source=linux&event_type=ssh_failure'
curl -F file=@samples/linux-auth.log -F format=linux -F year=2026 \
  -F timezone_offset=+00:00 http://127.0.0.1:8765/api/import

Date filters accept ISO 8601 timestamps; dates without offsets use UTC. User, IP, host and event type filters use exact stored values. Search is a case-insensitive literal substring. Limit: 1–200; default: 50.
